# Adult Weight Analysis: Descriptive Statistics & Data Distribution (Excel)

An Excel project that analyses the weights of 50 adults using descriptive statistics, frequency distributions and charts.

## Problem Statement
Analyse the weight data of 50 adults to understand the average weight, the most common weight range, and how the data is spread (distribution).

## Tools Used
- **Excel formulas:** SUM, COUNT, AVERAGE, MEDIAN, MODE, COUNTIF, COUNTIFS, MIN, MAX
- **Techniques:** Frequency Distribution, Relative & Cumulative Frequency
- **Charts:** Dot Plot, Histogram, Relative Frequency Histogram (with cumulative line), Pie Chart

## Key Questions
1. What are the Mean and Median weight of the 50 adults?
2. Which weight category holds the most people (Mode / peak bin)?
3. What percentage of people weigh 150 or less?

## Key Insights
| Measure | Result |
|---|---|
| Sample size | 50 adults (min 110, max 180) |
| Mean | **145.8** |
| Median | **145** (average of 25th & 26th values) |
| Mode | **Bimodal:** 170 and 150 (6 adults each) |
| Peak bin | **150** with 11 adults (22%) |
| Weight ≤ 150 | **64%** (32 of 50 adults) |

- Mean (145.8) is very close to the Median (145), so the distribution is nearly symmetric.
- Most adults fall between 140 and 170; extreme weights (110 and 180) are rare.

## Workbook Structure
| Sheet | Purpose |
|---|---|
| Project Overview | Problem statement, questions, live key findings, sheet guide |
| Weights | Raw data + Mean, Median, Mode calculations |
| Frequency Table | Count of each distinct weight |
| Dot Plot | One dot per adult, stacked by weight |
| Histogram | Bins of 10 and frequency histogram |
| Relative Freq | Frequency as % of total |
| RF Histo | Relative frequency histogram + cumulative % |
| Pie | Share of adults per weight bin |
